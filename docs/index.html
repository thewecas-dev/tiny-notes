Send a secret that deletes itself

Tiny Notes turns a password, API key or private message into a one-time link. The note is encrypted in your browser, and it is erased as soon as it has been read or its timer runs out.

Write a secret note Free. No sign-up. Nothing to install.

How it works

  1. Write your note

    Paste the text, then pick how many times it can be opened and how long it should last.

  2. Share the link

    You get a short link. Send it through chat or email to the one person who needs it.

  3. It is gone after reading

    Once the last view is used or the time is up, the note is deleted and the link stops working.

Private by design

  • End-to-end encrypted

    Your browser locks the note with AES-256 before it leaves your device. Only the locked text is stored.

  • The key never reaches the server

    The key travels inside your link, in the part browsers never send. Without the link, the note cannot be opened by anyone, including us.

  • One view means one reader

    A one-view note goes to exactly one person. If someone else got there first, your recipient sees that it is gone.

  • Safe from link previews

    Opening the link only shows its status. The note is used when the reader presses Reveal, not before.

  • No accounts, no profiles

    There is nothing to sign up for and nothing that identifies who wrote or read a note.

  • You set the limits

    1 to 100 views, and a lifetime from 1 minute to 7 days. Up to 75 KB of plain text per note.

What people send

  • Passwords and logins

    Hand over a Wi-Fi password or a shared account without leaving it in chat history.

  • API keys and tokens

    Pass a credential to a teammate once, instead of pasting it into email or a ticket.

  • Recovery codes and PINs

    Send a one-time code that should not be sitting in an inbox next week.

  • Private messages

    Anything meant to be read once and then forgotten.

Questions

Can Tiny Notes read my note?

No. Your browser encrypts the note before it is sent, and the key stays in the link you share. The server only ever stores locked text it has no key for.

What happens after the note is read?

It is deleted from the server as soon as its last allowed view is used, or when its timer runs out, whichever comes first. It cannot be recovered.

Do I need an account?

No. There is nothing to sign up for or install, and it is free.

Will a link preview in a chat app use up my note?

No. Opening the link only shows how many views are left. The note is used only when the reader presses Reveal note.

How much text can I send?

Up to 75 KB of plain text per note, which can be opened 1 to 100 times and can last from 1 minute to 7 days.

Ready to send one?

It takes a few seconds, and the first load of the app can take a little longer while it wakes up.
